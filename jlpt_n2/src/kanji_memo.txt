# 한자 기억법: 字|기억법  (유래와 별도. 실제 생활 장면 + 이미 아는 한국어 한자어로 연결)
濃|농사(農)지은 물(氵)은 흙이 섞여 진하다. 커피를 진하게 = 농도(濃度)가 높다. 아는 말: 농도·농후
競|두 형(兄兄)이 나란히 서서(立) 누가 빠른지 겨룬다 → 경쟁(競争)·경기(競技)·경마(競馬)
技|손(扌)으로 나뭇가지(支)를 깎아 물건을 만드는 솜씨 → 기술(技術)·기능(技能)·특기
消|촛불에 물(氵)을 부으면 불이 작아지다(肖) 꺼진다 → 소화기(消火器)·소멸·취소(取消)
毒|풀(屮) 중에 먹으면 안 되는(毋) 것 → 독. 아는 말: 독약(毒薬)·중독(中毒)·소독(消毒)
構|나무(木)를 우물 정(井)자처럼 엇갈려 짜서 뼈대를 세운다 → 구조(構造)·구성(構成)
知|화살(矢)처럼 빠르게 입(口)으로 답할 수 있다 = 안다 → 지식(知識)·통지(通知)
人|두 다리로 서 있는 사람의 옆모습 → 인간(人間)·인구(人口)
睡|눈(目)꺼풀이 아래로 축 처지면(垂) 졸린 것 → 수면(睡眠)
眠|눈(目)을 감고 쉬는 백성(民) → 잠자다. 수면(睡眠)·동면(冬眠)·불면증
資|다음(次)을 위해 모아 둔 돈(貝) → 자금(資金)·자원(資源)·투자(投資)
源|물(氵)이 처음 솟는 언덕 아래(原) → 근원. 원천(源泉)·자원(資源)·기원
補|옷(衤)에 구멍이 나면 천을 대서 깁는다 → 보충(補充)·보수(補修)·후보
説|말(言)로 풀어서 상대를 기쁘게(兌) 납득시킨다 → 설명(説明)·소설(小説)·연설
教|아이(子)를 회초리(攵)로 가르치는 모습 → 교육(教育)·교사(教師)
鮮|생선(魚)과 양고기(羊)는 갓 잡은 것이 최고 → 신선(新鮮)·선명(鮮明)
各|발(夂)이 각자 자기 집(口)으로 들어간다 → 각각(各各)·각자(各自)·각국
大|팔다리를 크게 벌린 사람 → 대학(大学)·대형(大型)
統|여러 실(糸)을 한 가닥으로 모아 채운다(充) → 통일(統一)·전통(伝統)·대통령
領|명령(令)을 내리는 우두머리(頁=머리) → 대통령(大統領)·영토(領土)·요령
制|자라는 나뭇가지를 칼(刂)로 쳐서 모양을 잡는다 → 제한(制限)·제도(制度)
卵|둥지 속 알 두 개가 나란히 놓인 모양 → 계란(鶏卵)·산란(産卵)
判|칼(刂)로 반(半)을 갈라 어느 쪽이 맞는지 가린다 → 판단(判断)·판결·재판
断|도끼(斤)로 이어진 실을 툭 끊는다 → 단절(断絶)·판단(判断)·중단(中断)
調|말(言)을 두루(周) 들어보고 고르게 맞춘다 → 조사(調査)·조절·강조
整|흩어진 것을 묶고(束) 두드려(攵) 바르게(正) 한다 → 정리(整理)·조정(調整)
赤|큰(大) 불(火)이 활활 = 새빨갛다 → 적자(赤字)·적십자(赤十字)
字|집(宀) 안에서 아이(子)가 배우는 것 → 글자. 문자(文字)·한자(漢字)
雑|옷(衣)을 아무렇게나 모아(集) 놓은 상태 → 섞이다. 잡지(雑誌)·복잡(複雑)
把|손(扌)으로 꽉 움켜쥔다 → 파악(把握)
逞|자기를 드러내며(呈) 성큼성큼 걸어간다(辶) → 굳세다, 씩씩하다(逞しい)
逸|토끼(兎)가 휙 달아난다(辶) → 놓치다, 벗어나다. 일탈(逸脱)·일화(逸話)
一|가로선 하나 = 하나 → 일(一)·통일(統一)
括|손(扌)으로 자루 입구를 꽉 묶는다 → 괄호(括弧)·일괄(一括)·총괄
思|머리(田)와 마음(心)으로 생각한다 → 사고(思考)·사상(思想)·의사(意思)
要|허리에 손을 얹은 여자(女) → 몸의 중심인 허리처럼 중요하다. 필요(必要)·요점(要点)
点|점을 쳐서(占) 불(灬)똥처럼 콕 찍은 자국 → 점수(点数)·요점(要点)
裂|옷(衣)이 쫙 갈라졌다(列) → 찢어지다. 분열(分裂)·결렬(決裂)
経|베틀의 날실(糸)이 처음부터 끝까지 지나간다 → 경과(経過)·경험(経験)·경제
過|시간이 지나간다(辶) → 과거(過去)·통과(通過)·과로(過労)
打|손(扌)으로 못(丁)을 탕 친다 → 타격(打撃)·타자(打者)
確|돌(石)처럼 단단해서 흔들리지 않는다 → 확실(確実)·확인(確認)·정확
信|사람(亻)이 한 말(言)은 믿는다 → 신용(信用)·신뢰·통신(通信)
特|소(牛) 중에서 특별히 고른 제사용 소 → 특별(特別)·특징(特徴)
定|집(宀) 안에 물건을 바르게(正) 딱 놓아 정한다 → 결정(決定)·예정·안정
評|말(言)로 공평하게(平) 따진다 → 평가(評価)·평론·호평
価|사람(亻)이 물건에 매기는 값 → 가격(価格)·물가(物価)·평가
改|자기(己)를 회초리(攵)로 쳐서 고친다 → 개선(改善)·개정(改正)·개혁
正|목표선(一)에 발(止)을 정확히 맞춘다 → 바르다. 정답(正答)·정확(正確)
備|사람(亻)이 화살통을 미리 채워 둔다 → 준비(準備)·대비·설비(設備)
黒|굴뚝(囪) 아래 불(灬) → 그을음으로 새까맣다 → 흑자(黒字)·흑백(黒白)
生|흙에서 새싹이 쑥 돋아나는 모양 → 생활(生活)·학생(学生)·발생
意|소리(音)가 마음(心)속에서 나는 것 = 뜻 → 의미(意味)·의견(意見)·주의
気|밥(米)을 지을 때 피어오르는 김(气) → 공기(空気)·기분(気分)·인기(人気)
地|흙(土)이 넓게 펼쳐진 곳 → 지구(地球)·지역(地域)·토지
悪|버금(亜)가는, 비뚤어진 마음(心) → 악(悪)·악화(悪化)·최악(最悪)
反|손(又)으로 벼랑(厂)을 밀어 젖힌다 → 반대(反対)·반성(反省)·위반
狂|개(犭)가 왕(王)처럼 날뛴다 → 미치다. 광기(狂気)·열광(熱狂)
偏|사람(亻)이 납작한(扁) 한쪽으로만 기운다 → 편견(偏見)·편식(偏食)
才|땅에서 막 돋아난 새싹 = 타고난 재능 → 천재(天才)·재능(才能)
能|곰처럼 힘이 센 동물 → 할 수 있다. 능력(能力)·가능(可能)·기능
辛|죄인 이마에 새기던 날카로운 바늘 → 따갑고 맵다. 신랄(辛辣)·고생(辛苦)
刑|틀(开)에 가두고 칼(刂)로 벌한다 → 형벌(刑罰)·형사(刑事)·사형
事|손에 붓을 쥐고 일을 기록한다 → 일. 사건(事件)·사고(事故)·식사
起|달리려고(走) 몸(己)을 일으킨다 → 기상(起床)·기립(起立)·제기
床|집(广)에 놓인 나무(木) 침대 → 침상. 기상(起床)·병상(病床)
収|손(又)으로 흩어진 것을 거두어 모은다 → 수입(収入)·수확·수집
湿|물(氵)기가 배어 축축하다 → 습도(湿度)·습기(湿気)
傾|사람(亻)이 고개를 갸웃 기울인다(頃) → 경향(傾向)·경사(傾斜)
向|집(宀)의 창문(口)이 한쪽을 향해 나 있다 → 방향(方向)·향상(向上)
視|제단(示)을 똑바로 바라본다(見) → 시력(視力)·시선·감시(監視)
察|집(宀)에서 제사(祭)를 지내며 꼼꼼히 살핀다 → 관찰(観察)·경찰(警察)·고찰
絞|실(糸)을 엇갈리게(交) 감아 꽉 조인다 → 짜다, 조르다. 교살(絞殺)
施|깃발(㫃)을 세우고 널리 베푼다 → 시설(施設)·실시(実施)·시행
設|말(言)로 지시하고 도구(殳)로 세운다 → 설치(設置)·설계(設計)·시설
育|갓난아이를 살(月)찌우며 기른다 → 교육(教育)·육아(育児)·체육
論|말(言)을 차례(侖)대로 따진다 → 토론(討論)·논문(論文)·결론
食|뚜껑 덮인 밥그릇 → 식사(食事)·음식(飲食)·식품
条|나무(木)의 가는 가지 하나하나 → 조건(条件)·조약(条約)·조항
件|사람(亻)이 소(牛)를 한 마리씩 세는 것 → 사건(事件)·조건(条件)·용건
誓|말(言)을 딱 끊어(折) 단단히 약속한다 → 맹세. 선서(宣誓)
時|해(日)의 움직임으로 재는 때 → 시간(時間)·시계(時計)·동시
的|흰(白) 과녁의 한가운데 → 목적(目的)·적중(的中)·~적(的)
関|문(門)의 빗장으로 연결한다 → 관계(関係)·관심(関心)·관문
与|손에서 손으로 건네주다 → 주다. 급여(給与)·관여(関与)·부여
則|솥(貝)에 칼(刂)로 새긴 법 → 규칙(規則)·원칙(原則)·법칙
追|길을 따라 뒤쫓아 간다(辶) → 추가(追加)·추구(追求)·추적
払|손(扌)으로 먼지를 털어 낸다 → 지불하다(払う). 불식(払拭)
妙|젊은(少) 여자(女)의 묘한 매력 → 묘하다. 미묘(微妙)·교묘(巧妙)
不|새가 하늘로 날아가 돌아오지 않는다 → 아니다. 불가능(不可能)·불안(不安)
議|옳은(義) 것을 말(言)로 의논한다 → 회의(会議)·의논(議論)·의원(議員)
相|나무(木)를 눈(目)으로 서로 마주 본다 → 서로. 상대(相手)·상담(相談)
当|밭(田)에 딱 맞게 해당한다 → 마땅하다. 당연(当然)·담당(担当)·당일
帰|빗자루(帚)를 들고 집으로 돌아간다 → 귀가(帰宅)·귀국(帰国)·복귀
省|눈(目)을 가늘게(少) 뜨고 살핀다 / 줄이다 → 반성(反省)·생략(省略)·성(省)
突|구멍(穴)에서 개(犬)가 갑자기 튀어나온다 → 돌연(突然)·충돌(衝突)·돌파
然|고기(月)를 불(灬)에 굽는 건 당연하다 → 그러하다. 자연(自然)·당연(当然)
潰|물(氵)에 귀한(貴) 둑이 무너진다 → 찌부러지다. 궤양(潰瘍)·궤멸
粗|쌀(米)을 대충 빻아 거칠다 → 조잡(粗雑)·조악(粗悪)
末|나무(木) 위쪽 끝에 긴 선 → 끝. 주말(週末)·월말(月末)·결말
熱|불(灬)을 활활 지펴 뜨겁다 → 열(熱)·열심(熱心)·가열
中|과녁 한가운데를 꿰뚫은 화살 → 가운데. 중심(中心)·중간
和|벼(禾)를 함께 먹는 입(口) → 평화롭다. 평화(平和)·조화(調和)·화해
愛|마음(心)이 끌려 돌아보며 걷는다 → 사랑. 애정(愛情)·연애(恋愛)
着|양(羊) 털옷을 몸에 딱 붙여 입는다 → 도착(到着)·착용(着用)·정착
柱|집의 중심(主)이 되는 나무(木) → 기둥. 전신주(電柱)
討|말(言)로 법도(寸)에 맞게 따져 친다 → 토론(討論)·검토(検討)·토벌
争|두 손이 하나를 서로 잡아당긴다 → 다투다. 전쟁(戦争)·경쟁(競争)
豊|제기(豆) 위에 곡식이 수북이 → 풍부하다. 풍작(豊作)·풍부(豊富)
富|집(宀)에 술단지가 가득 → 부자. 부자(富者)·풍부(豊富)·빈부
略|밭(田)의 경계를 대충 그려 줄인다 → 생략(省略)·간략(簡略)·전략
涼|물(氵)가 높은 언덕(京)은 바람이 시원하다 → 서늘하다. 청량(清涼)
拡|손(扌)으로 넓게(広) 펼친다 → 확대(拡大)·확장(拡張)
充|아이(𠫓)가 자라 몸이 꽉 찬다 → 채우다. 충분(充分)·충전(充電)·보충
救|구하려고(求) 손(攵)을 뻗는다 → 구조(救助)·구급차(救急車)
厚|벼랑(厂) 아래 겹겹이 쌓인 두께 → 두껍다. 후생(厚生)·농후
先|발(⺧)이 사람(儿)보다 앞에 나간다 → 먼저. 선생(先生)·우선(優先)
順|냇물(川)이 머리(頁) 쪽에서 아래로 차례대로 흐른다 → 순서(順序)·순조
仮|사람(亻)이 뒤집어(反) 쓴 가짜 얼굴 → 임시. 가정(仮定)·가설(仮説)
予|베틀 북이 미리 앞으로 나간다 → 미리. 예정(予定)·예약(予約)·예보
約|실(糸)로 꽁꽁 묶어 둔 약속 → 약속(約束)·예약(予約)·계약(契約)·요약
防|언덕(阝)에 둑을 쌓아 물을 막는다 → 방지(防止)·예방(予防)·방어
飛|새가 두 날개를 펼치고 나는 모양 → 비행기(飛行機)·비약
散|막대(攵)로 두드리면 이리저리 흩어진다 → 산책(散歩)·해산·분산
敏|매일(每) 회초리(攵) 맞으며 훈련해 재빠르다 → 민감(敏感)·민첩·과민
感|모든(咸) 것이 마음(心)에 와닿는다 → 감동(感動)·감사(感謝)·감기
裏|옷(衣) 속감 → 안쪽, 뒷면. 표리(表裏)·이면
付|사람(亻)에게 손(寸)으로 건네준다 → 붙이다. 교부(交付)·부록·접수(受付)
致|목적지에 이르게(至) 한다 → 일치(一致)·유치(誘致)·치명적
